Welcome to the **CSS Utilities** documentation!

## What are CSS Utilities?

CSS Utilities are custom, reusable utility classes built on top of Tailwind CSS v4's `@utility` directive. They extend the default Tailwind utility set with project-specific needs — like controlling text rendering, touch behavior, and more.

Each utility is defined in `src/styles/globals.css` and is available globally across the app.

## How to use the docs

The docs are organized into 4 sections:

- [Guides](/docs/css-utils/guides): Core concepts, step-by-step tutorials, and best practices for creating CSS utilities.
- [API Reference](/docs/css-utils/api-reference): Detailed reference for every available utility.
- [Anchor Positioning](/docs/css-utils/anchor-positioning): Complete reference for CSS anchor positioning — tethering and positioning elements relative to each other.
- [Transitions & Animations](/docs/css-utils/transitions-and-animations): `@starting-style`, View Transitions, and scroll-driven animations.

## Pre-requisite knowledge

Our utilities are built with [Tailwind CSS v4](https://tailwindcss.com/docs). Familiarity with:

- CSS custom properties
- Tailwind's `@utility` directive
- CSS layers

…will help you get the most out of these docs.
