# Custom CSS Utilities

This project has a custom Tailwind CSS v4 utility framework. Before writing any CSS or styling, read the docs at `src/styles/docs/` — especially the component API references. Most common UI patterns already have dedicated utilities (`btn`, `card`, `dialog`, `popover`, `menu`, `avatar`, `divider`, etc.). Do not write custom CSS if a documented utility already covers the use case.

Use plain Tailwind utilities only for the fine-tuning a custom utility deliberately leaves open (sizing, spacing, colors) — the docs show this pattern.
